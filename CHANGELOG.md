# Changelog

All notable changes to this project are documented here. The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/) and the project uses [Semantic Versioning](https://semver.org/).

## [1.0.0] - 2026-10-27

First public release.

### NotchPilot
- Notch with battery %, time remaining, CPU and GPU temperature.
- Four power modes (Maximum Saver, Battery Saver, Normal, Performance) via copies of the built-in Windows plans.
- Game mode with HP Omen BIOS fan control: Quiet, Medium, Game, Max presets and Auto (BIOS), with a safety temperature cut-off.
- Live game FPS in the notch (DirectX 11/12, via ETW).
- 60 Hz display and discrete GPU switch-off in Maximum Saver.
- Optional notch pet, genie animations, six UI languages.
- One-file installer with admin mode (no UAC prompts) and an uninstaller.

### PowerNotch
- Same notch and power modes for any Windows 10/11 laptop, without fan control.
- Per-mode CPU cap, brightness and screen-off settings.
- Optional FPS indicator, animations, six UI languages.
